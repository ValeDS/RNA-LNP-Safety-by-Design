# Data files

`inputs/` contains synthetic intermediate files and derived GSE171964 summaries required by the scripts. They are included to make the workflow independent of the authors' local directory structure.

`primary/` contains the principal machine-readable outputs used in the manuscript. `revision/` contains selected outputs from the sensitivity and audit analyses.

All virtual-patient, formulation and response records are synthetic. The GSE171964 files in this repository are derived program-level summaries and cell-count summaries. Raw single-cell data remain available from GEO under accession GSE171964.
